# Shiva Singh — AI & Generative AI Developer Portfolio

A responsive developer portfolio website built with **React**, **Vite**, and real-time **GitHub REST API** synchronization. Showcases AI & Generative AI projects, computer vision applications, robotics hardware builds, experience, and educational background.

---

## 🌟 Highlights & Features

- **Live GitHub Synchronization:** Dynamically connects to [`@Shiva272001`](https://github.com/Shiva272001) using the GitHub REST API to fetch real-time public repositories, star counts, fork counts, primary languages, and latest update timestamps.
- **Instant Project Reflection:** Any new repository or update pushed to GitHub is automatically reflected in the portfolio without needing manual code changes.
- **Interactive Project Filtering & Search:** Category filters (*AI & Generative AI*, *Computer Vision*, *Robotics & Hardware*, *Machine Learning*, *Cloud & Tools*) and a live search input.
- **Direct Live Demo & Code Links:** Direct links to code on GitHub and live deployed applications on Vercel and Render.
- **Professional Social Links:** Direct integration with [LinkedIn](https://www.linkedin.com/in/shiva-singh2001) and [GitHub](https://github.com/Shiva272001).
- **Responsive & Modern Dark Tech Aesthetic:** Built with custom typography (`Manrope` + `DM Mono`), smooth scrolling, and mobile-friendly layouts.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite 6
- **Styling:** Custom CSS with CSS variables, responsive grid & flexbox
- **APIs:** GitHub REST API (dynamic repository & user data)
- **Deployment:** Vercel / Netlify / Render ready

---

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Shiva272001/Shiva-Singh.git
   cd Shiva-Singh
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
   The optimized production bundle will be generated in the `dist` directory.
